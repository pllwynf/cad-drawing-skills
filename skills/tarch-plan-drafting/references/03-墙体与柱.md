# 墙体与柱

## 墙体的本质

墙对象 = **柱间或墙角之间、特性相同的一段直墙或弧墙单元**。它不只是两根线：
除了几何，还带墙类型、材料、内外属性、高度。天正靠这些属性做：
墙角自动修剪、按材料优先级决定谁断开谁、与柱子和门窗联动、房间围合与面积。

### 墙基线（最重要）

- 基线是**定位线**，通常在墙体内与轴线重合，也可以在墙外（此时左右宽有一为负）。
- 两条边线 = 基线按左右宽度偏移；墙体长度指基线长度；弧窗宽度按基线弧长算。
- 转角、连接、延伸、裁剪全按基线判断 → **相接的墙基线必须准确交于一点**。
- 基线**不许重合**：出现重合墙天正会警告并阻止。
- 出图不打印基线；要看它：状态栏"基线"按钮，或把二维表现切到"单双线"。

### 用途（6 类）

| 用途 | 是否加粗/填充 | 是否参与房间面积 | 备注 |
|---|---|---|---|
| 内墙 | 是 | 是 | 常规 |
| 外墙 | 是 | 是 | 节能/立面按它算 |
| 分户 | 是 | 是 | 户与户之间 |
| 虚墙 | 是 | 是（作逻辑分隔） | 不建三维，可算面积 |
| 卫生隔断 | 否 | 否 | 洁具隔断 |
| 矮墙 | 否 | 否 | 女儿墙/檐口，优先级最低 |

### 材料与断开优先级

钢筋混凝土 > 石 > 砖 > 填充墙 > 玻璃幕墙 > 轻质隔墙。高优先级打断低优先级。
材料同时决定二维填充与三维材质。

## 绘制墙体 HZQT / TGWall

对话框（**非模态**，不关也能画）参数：

| 参数 | 说明 |
|---|---|
| 左宽 / 右宽 | 沿基线方向的左侧/右侧宽度；矩形画墙时对应"基线内侧/外侧"；可为负、可为 0 |
| 左保温 / 右保温 | 开关 + 数值（默认 80） |
| 墙宽组 | 按材料预置的常用宽度，用过会自动进列表 |
| 墙高 | 墙底到墙顶；默认层高；填 0 则三维不生成 |
| 底高 | 本图 ±0 到墙底 |
| 墙体填充 / 保温填充 | 开则用专用图案，关则跟随【墙柱填充】设置 |
| 材料 | 钢筋砼/混凝土/砖/耐火砖/石材/毛石/填充墙/空心砖/加气块/石膏板 |
| 用途 | 内墙/外墙/分户/卫生隔断/虚墙/矮墙 |

工具栏三个画法：

1. **直墙**：`起点或[参考点(R)]<退出>` → 连续给点 → `直墙下一点或[弧墙(A)/矩形画墙(R)/闭合(C)/回退(U)]<另一段>`
   - 输入 **`R` = 矩形画墙**：给对角两点，一次生成一圈 4 段墙，最省事。
2. **弧墙**：起点 → 终点 → 弧上一点（或 `R` 给半径）。
3. **矩形布置**：同 `R`。

其它按钮：`墙体删除`（按当前类型批量删）、`墙体编辑`（框选提取参数批量改）、
`替换图中已插入的墙`、`拾取墙体参数`、`自动捕捉`、`模数开关`。

玻璃幕墙单独一页：立柱生成规则（等距间距值 / 等分接近值）、立柱与横梁截面、玻璃偏移、隐框。

## 单线变墙 DXBQ（批量成墙的主力）

对话框：材料、墙高、底高、墙厚（带步进列表）。三种模式：

| 模式 | 选中什么 | 结果 |
|---|---|---|
| 轴线生墙 | 框选轴网（只选轴线层） | 沿轴线生成墙，墙厚一次给；外墙/内墙分两次做 |
| 单线变墙 | 任意图层的 LINE/ARC/PLINE | 搜外围闭合线当外墙，伸出的墙肢不当外墙 |
| 多轴生墙 | 两点栏选轴线 | 只生成被选到的轴 |

要点：轴线生墙会**保留轴线并智能清掉轴线伸出部分**。

## 柱

### 标准柱 BZZ / TGColumn

1. 设参数：截面形状（矩形/圆柱/正多边形 3/5/6/8/12）、尺寸、柱高、柱偏心、柱转角、材料。
2. 选布置方式（三个工具栏按钮）：
   - **点选插入柱**：优先吸轴线交点；没交点就按当前 UCS 插在点取位置。
     提示 `点取位置或[转90度(A)/左右翻(S)/上下翻(D)/对齐(F)/改转角(R)/改基点(T)/参考点(G)]<退出>`
   - **沿一根轴线布置**：选一根轴，该轴与其他轴的所有交点一次布柱。
   - **矩形区域轴线交点布置**：给两个角点，范围内所有轴线交点一次布柱 —— **批量布柱首选**。
3. 其它按钮：`柱删除`、`柱编辑`（批量改）、`替换图中已插入柱子`、
   `选择 Pline 创建异形柱`、`在图中拾取柱子形状或已有柱子`。

柱插入方向永远跟随当前坐标系 X 轴；UCS 转了柱也跟着转。

### 角柱 JZ / 构造柱 GZZ

- `JZ` 角柱：在墙角插入形状随墙的 L 形柱，各肢长度/宽度可调，默认宽 = 墙宽。
- `GZZ` 构造柱：墙角或墙内插入，按 A-C / B-D 两向尺寸，可选对齐边，**只生成二维**。
- 异形柱：`BZZ` 里用闭合 Pline 创建，或对已有柱右键"布尔运算"（并/差/交）。

### 柱的可读写属性

| 属性 | 说明 |
|---|---|
| `Width` / `Deep` | 矩形柱两向尺寸 |
| `TotalWidth`（墙） | 墙总厚 |
| 柱高 | 默认层高，可改 |

柱与墙的连接形式由**材料**决定，柱在不同材料墙上的自动剪裁效果不同。
