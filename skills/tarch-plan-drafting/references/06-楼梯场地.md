# 楼梯、台阶与场地构件

## 双跑楼梯 SPLT / TRStair

最常见的楼梯形式：两跑直梯段 + 一个休息平台 + 扶手栏杆，一个自定义对象（`TDbRectStair`）。

面板参数：

| 参数 | 说明 |
|---|---|
| 梯间宽 | 楼梯间总宽，可按 `<` 按钮到图上量取 |
| 梯段宽 | 默认由总宽二等分；可量取 |
| 井宽 | 井宽 = 梯间宽 − 2×梯段宽，三维互算，可 0 |
| 楼梯高度 | 总高，默认取层高；层高不等时手改 |
| 踏步总数 | 默认 20，**关键参数** |
| 一跑/二跑步数 | 由总数推算；总数为奇数时先增二跑 |
| 踏步高度 | 给概略值，系统按总高/踏步数反算精确值（可能有舍入误差） |
| 踏步宽度 | 梯段方向的踏步宽，用户优先决定 |
| 休息平台 | 矩形 / 弧形 / 无 |
| 平台宽度 | 规范要求 ≥ 梯段宽 |
| 踏步取齐 | 齐平台 / 居中 / 齐楼板 / 自由（拖夹点） |
| 层类型 | 首层=只给一跑下剖断；中间层=一跑双剖断；顶层=一跑无剖断 |
| 扶手高宽 | 默认 900 高，60×100 断面 |
| 扶手距边 | — |
| 疏散半径 | 不画 / 单侧（楼板侧或平台侧）/ 双侧 |

插入：`点取位置或[转90度(A)/左右翻(S)/上下翻(D)/对齐(F)/改转角(R)/改基点(T)]<退出>`。

夹点：四角点=移动，两侧中点=改梯段宽，剖切线两端=改剖切位置。

**层类型必须按楼层设置**，否则平面图的剖断线是错的。

## 房间与面积

| 命令 | 用途 |
|---|---|
| `SSFJ` 搜索房间 | 创建/更新房间与建筑面积对象（墙围合自动搜） |
| `CXMJ` 查询面积 | 查房间面积并标注（单行/两行文字） |
| `FJLK` 房间轮廓 | 沿房间内侧生成轮廓线（踢脚等用） |
| `XGBJ` 修改边界 | 快速调房间边界 |
| `ZZFJ` 字转房间 | 房间内文字按设置转成房间对象 |
| `MJJS` 面积计算 | 对房间/数字/Pline/填充/阳台/防火分区做加减 |
| `MJTJ` 面积统计 | 统计同类面积并出表 |
| `TNMJ` 套内面积 | 按住宅规范算套内 |
| `GTMJ` 公摊面积 | 定义要分摊的公用面积 |
| `ZZMJ` 住宅面积 | 各套型分摊后经济技术指标 |

房间对象落在 `SPACE` 层；面积填充在 `SPACE_HATCH`。
**虚墙**可以用来把一个大空间划成两个可分别算面积的区域。
