# 立面、剖面与图框

## 前置条件：工程管理 GCGL

`JZLM`（建筑立面）和 `JZPM`（建筑剖面）**依赖工程管理里的楼层表**。没有工程/楼层表会直接弹警告：
"请打开或新建一个工程管理项目，并在工程数据库中建立楼层表！"

工程管理（文件布图菜单）：

1. 新建工程并命名；工程下按"平面图/立面图/剖面图"分类添加图纸。
2. 楼层栏填 `起始层号-结束层号` + 层高，定义标准层。
3. 同层图纸可框选标准层范围；不同文件则指定文件名。
4. 执行 `JZLM`/`JZPM` **前必须先存盘**，否则无法对更新的对象生成立面/剖面。

## 建筑立面 JZLM

```
请输入立面方向或[正立面(F)/背立面(B)/左立面(L)/右立面(R)]<退出>:  F
请选择要出现在立面图上的轴线:     选同方向的开间/进深轴线（选轴号无效）
```

然后弹【生成立面】面板：

| 控件 | 说明 |
|---|---|
| 多层消隐 / 单层消隐 | 多层慢但准（能处理楼梯扶手伸入上层）；单层快 |
| 内外高差 | 室内地面与室外地坪之差 |
| 出图比例 | 立面出图比例 |
| 左侧标注 / 右侧标注 | 竖向标注（楼层标高 + 尺寸） |
| 绘层间线 | 是否画层间水平线 |
| 忽略栏杆 | 复杂造型栏杆（`TCH_RAIL`）面数极多，勾上显著提速 |

点"生成立面"→ 选保存文件 → 自动生成并打开。图层名 = 原构件层加 `E_` 前缀。

**构件立面 GJLM**：对单个构件/楼梯/三维图块出立面或顶视图，不需要工程管理。
提示 `请输入立面方向或[正立面(F)/背立面(B)/左立面(L)/右立面(R)/顶视图(T)]` → 选构件 → 回车。

## 建筑剖面 JZPM

```
请点取一剖切线以生成剖视图:   点首层的剖切线（剖切符号）
请选择要出现在立面图上的轴线: 点首末轴线，或回车不要轴线
```
面板同立面（多层/单层消隐、内外高差、比例、左右标注、绘层间线、忽略栏杆）。
生成后存文件打开。

**构件剖面 GJPM**：单构件剖切出二维剖面，不需要工程管理。
图层名前缀 `S_`。

## 图框与布图

### 插入图框 CRTK

| 控件 | 说明 |
|---|---|
| 标准图幅 | A4~A0 五档 |
| 图长 / 图宽 | 直接键入，或显示所选标准图幅尺寸 |
| 横式 / 立式 | 图幅方向 |
| 加长 | 国标加长图幅下拉 |
| 自定义 | 记忆最近 20 个非标准尺寸 |
| 比例 | 出图比例，**必须与打印对话框一致** |
| 图纸空间 | 勾选后切到布局，比例自动 1:1 |
| 会签栏 | 左上角加会签栏（从图框库选） |

图框与标题栏统一由**图框库**管理；带属性标题栏支持生成图纸目录。
旧版 `Label1.dwg / Label2.dwg` 的做法已废弃。
自定义图框见 `21layoutfiles/图框的用户定制`（`TTitleFrame.xml`）。

### 其它布图命令

| 命令 | 用途 |
|---|---|
| `GCGL` 工程管理 | 多图/多层的工程组织，立剖面的数据源 |
| `CHBZ` 拆图/布图 | 按图框布置 |
| `SWZH` 三维组合 | 多标准层组合成整栋三维 |
| `DWGEXPORT` / 整图导出 | 导出为纯 AutoCAD 图（天正对象分解，尺寸退化为兼容样式） |
| 格式转换导出 | 转 T3/低版本、转 PKPM 等 |

## 输出到别的环境时的注意

- 交给非天正用户：用"整图导出"，天正对象会被分解，尺寸按当前比例退化成 `DIMN`/`DIMN200` 样式。
- 直接给天正用户：保留原样即可，别 EXPLODE。
- 分解后的墙/门窗不再有智能联动，等于交了一张"死图"。
