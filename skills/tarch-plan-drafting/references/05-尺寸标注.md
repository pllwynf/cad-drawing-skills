# 尺寸标注

## 天正尺寸 vs AutoCAD 尺寸

- 天正尺寸是**自定义对象**，以"连续区间"为基本单元：一串连续区间属于**同一个对象**，
  夹点编辑可以整体调、单个区间调、区间文字调。AutoCAD 尺寸每个区间都是独立对象。
- 单位默认毫米；切到"以米为绘图单位"后按米标，精度默认两位小数。
- 样式基于四种：`_TCH_ARCH`（线性，含 mm→m、m→m 变体）、`_TCH_ARROW`（角度）、
  `_TCH_ARC`（弧长）、`_TCH_RAD`（半径/直径）。改 `DDIM` 里对应样式即可全局生效。
- 分解后退化为 AutoCAD 尺寸；`CCZH` 可反向把 AutoCAD 尺寸转成天正尺寸。
- 两个开关：`尺寸自调`（文字拥挤自动移位）、`尺寸检查`（与测量值不符的文字变红并加括号）。

## 三道尺寸线的来源

| 道次 | 内容 | 命令 | 是否联动 |
|---|---|---|---|
| 一 | 总尺寸 | `ZWBZ` 自动 | 否 |
| 二 | 轴线间距 | `ZWBZ` 自动 | 否 |
| 三 | 门窗定位 | `MCBZ` | **是**，门窗宽度变化尺寸跟着变 |

`ZWBZ` 出的第一二道落在 `AXIS` 层；其它标注默认在 `DIM` 层。

## 各标注命令

### MCBZ 门窗标注（第三道）

```
请用线选第一、二道尺寸线及墙体
起点<退出>:   在第一道尺寸线外侧一点
终点<退出>:   在外墙内侧一点
选择其他墙体: 补充被内墙断开的墙段，回车结束
```
有第一二道尺寸时自动对齐生成第三道；没有时就在你选的位置直接标。
联动范围由起始/终止尺寸界线与"尺寸关联夹点"围合决定；带形窗、转角窗、弧窗**不支持**联动。
镜像/复制出来的新门窗不会自动加标注。

### LDBZ 两点标注

给两点连线经过的墙线/轴线/门窗/柱标注。面板可勾 `标注对象`（墙/轴线/柱/门窗，不能全不勾）、
`墙中标注` / `墙面标注`（互锁）、`标总尺寸`（出两道）。适用于快速出整跨尺寸。

### NMBZ 内门标注

```
请用线选门窗，并且第二点作为尺寸线位置!
起点或[垛宽定位(A)]<退出> → 终点<退出>
```
面板三种定位：`轴线定位` / `垛宽定位` / `轴线+垛宽`。

### ZDBZ 逐点标注（最通用）

面板：标注样式、`自由标注` / `水平标注` / `垂直标注` 三种模式。

**应答顺序（三点式，错了会出废尺寸）**：
```
起点或[参考点(R)]<退出>          ← 第 1 个标注点
第二点<退出>                     ← 第 2 个标注点
请点取尺寸线位置或[更正尺寸线方向(D)]<退出>   ← 尺寸线位置
请输入其他标注点或[撤消上一标注点(U)]<结束>   ← 后续点，空回车结束
```

### 其它

| 命令 | 用途 | 备注 |
|---|---|---|
| `QHBZ` 墙厚标注 | 两点连线穿过的墙厚 | 墙内有轴线时标左右宽，无轴线标总宽 |
| `PXBZ` 平行标注 | 平行轴线/对象间距 | 可设图层过滤（默认 DOTE） |
| `KSBZ` 快速标注 | 框选天正实体批量出标注 | 只认墙/门窗/柱 |
| `ZYBZ` 自由标注 | 选图形后一把出外包尺寸 | 选项 `整体(T)/连续(C)/连续+整体(A)` |
| `WBCC` 外包尺寸 | 一次修好 4 个方向两道尺寸的 16 处齐边 | 不需输墙厚 |
| `HBBZ` 合并标注 | 多个尺寸外侧加一道总尺寸 | 方向/类型必须一致 |
| `LTBZ` 楼梯标注 | 踏步、井宽、梯段宽、平台深 | 可设精度；`S` 键设置 |
| `BJBZ` / `ZJBZ` | 半径 / 直径 | 文字放不下自动引到外侧 |
| `JDBZ` 角度 | 两直线内角 | 点两线 + 尺寸线位置 |
| `HCBZ` 弧弦标注 | 弧长/角度/弦长，可互转 | 光标位置决定类型 |
| `TKBZ` 图块标注 | 图块边界尺寸 | 支持多选 |
| `DWBZ` 定位标注 | 图块定位尺寸 | X/Y/双向/沿线 |

## 尺寸编辑

| 命令 | 作用 |
|---|---|
| `CCZT` 尺寸自调 | 文字自动避让 |
| `CCDD` 尺寸打断 | 一组断成两组 |
| `QXCC` 取消尺寸 | 删掉一个区间（标注断开） |
| `CFQJ` 拆分区间 | 一个区间分成多个 |
| `HBQJ` 合并区间 | 相邻区间合并 |
| `DFQJ` 等分区间 | 按等分数细分 |
| `DSBZ` 等式标注 | 标成 `n×d=总长` |
| `ZBCC` 增补尺寸 | 已有标注加点 |
| `CJYS` 裁剪延伸 | 尺寸线按新位置裁/延 |
| `CCDJ` 尺寸等距 | 多个标注按指定距离排齐 |
| `DQBZ` 对齐标注 | 按参考标注对齐 |
| `LJCC` 连接尺寸 | 平行多个标注连成一个 |
| `WZFW` 文字复位 / `WZFZ` 文字复值 | 位置/数值复位 |
| `QHJB` 切换角标 | 角度/弧长/弦长互转 |
