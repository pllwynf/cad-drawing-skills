# 图层标准与对象模型

## 图层标准（TArch.lay / LAYERDEF.DAT）

天正对象自动落到标准图层，**按层筛选是自动化最可靠的手段**。
下表为「天正」标准（`图层标准 TArch`）；另有一套国标中文标准 `GBT18112-2000`，
用 `TCGL`（图层管理）切换，`TCZH`（图层转换）把已有图纸整体转标准。
颜色/线型列不能随便改（改了天正会按图层关键字恢复）。

## 对象类型与可读写属性

用 `count_entity_types` 可以按对象名统计，这是**验收的硬指标**。

| 对象 | 出现于 | 可读写的关键属性 | 只读/危险 |
|---|---|---|---|
| `TDbWall` 墙 | 绘制墙体 / 单线变墙 | `TotalWidth`、`LeftWidth`、`RightWidth`、墙高、底高、材料、用途 | 基线不可重设 |
| `TDbColumn` 柱 | 标准柱 / 角柱 / 构造柱 | `Width`、`Deep`、柱高、材料、转角 | — |
| `TDbOpening` 门窗 | 门窗 / 带形窗 / 转角窗 | `Width`、`Height`、`WinSill`、`Label` | 门/窗类型只读；**勿读 `BayThick`** |
| `TDbRectStair` 双跑楼梯 | 双跑楼梯 | `StepNum1/2`、`StairWidth`、`StepWidth`、平台宽、层类型 | — |
| `TDbDimension2` 天正尺寸 | 各标注命令 | 区间值、文字、样式 | 区间结构复杂，改值优先用命令 |
| `TDbAxisLabelSet` 轴号 | 轴网标注 | 起始轴号、轴号规则 | 与轴线不联动 |
| 房间 `TDbSpace` | 搜索房间 | 名称、编号、面积（计算值） | 面积只读 |

## 移动/变换的坑

- `Move` 必须传 `VARIANT(VT_ARRAY|VT_R8, [x, y, 0])`；传 tuple/list 报 `E_INVALIDARG (-2147024809)`。
- `TransformBy` 传 16 元素数组会报"安全数组维数不正确"，基本不可用 —— 改用 `Move` + `Rotate`。
- 复制/镜像后的墙与造型会脱离原有连接关系，要跑 `XQJ`（修墙角）重新融合。
