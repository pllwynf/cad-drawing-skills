# 门窗

## 本质

门窗 = **附属于墙体、必须在墙上开洞、带编号**的自定义对象。插入后墙体外轮廓不变，
但墙的粉刷面积/开洞面积立刻更新。两类：

- `TCH_OPENING`：只附属于一段墙，**不能跨墙角**（普通门/窗/洞）。
- `TCH_CORNER_WINDOW`：跨一个或多个转角（转角窗、带形窗），离开原墙就可能不正确，
  因此不能像前者那样随意编辑。

参数：编号、宽、高、窗台高（窗）/门槛高（门）、个数（连续插入）、二维与三维图例。
把门窗高设为 0 → 三维不开洞。

## 九种定位方式（`MC` / TOpening）

命令 `MC`，面板左侧三个图标是**定位模式**，右侧是**类型**。

| 方式 | 命令提示 | 适用 |
|---|---|---|
| 自由插入 | `点取门窗插入位置(Shift-左右开,Ctrl-上下开)<退出>` | 方案阶段，快但不定距 |
| 顺序插入 | `点取墙体` → `输入从基点到门窗侧边的距离或[取间距(L)]` | 沿墙连续布门窗、幕墙 |
| 轴线等分插入 | `点取门窗大致的位置和开向` → `指定参考轴线(S)/门窗或门窗组个数(1~3)<1>` | 外墙窗按开间居中；支持 `Q` 多墙插入 |
| 墙段等分插入 | 同上，但按**墙段**等分，各门窗间墙垛相等 | 内墙一排门 |
| 垛宽定距插入 | `点取门窗大致位置` （用面板里设的垛宽值） | **内门**最常用 |
| 轴线定距插入 | 自动找最近轴线与墙交点作参考 | 有轴网的定位 |
| 按角度定位 | `点取弧墙` → `门窗中心的角度` | 弧墙上的直窗 |
| 智能插入 | `点取门窗的大致位置或[设为轴线定距(Q)]` | 中段自动居中、两端按垛宽/轴线定距 |
| 满墙插入 | `点取墙段` | 宽度由系统按墙段定（带形窗、落地窗） |

补充两个：
- **插入上层门窗**：同一洞口上方叠一个同宽不同高的窗（厂房高窗）。
- **在已有洞口插入多个门窗**：防火门/户门/车库门叠在已有门洞上。

## 面板里的实用按钮

| 按钮 | 作用 |
|---|---|
| 替换 | 用当前参数批量替换图中门窗——**改门/窗类型靠它**（见下） |
| 拾取（参数提取） | 点一个已有门窗，把它参数读进面板 |
| 删除 | 批量删门窗 |
| 类型 | 打开编号设置（编号前缀规则） |
| 查表 | 校验图中已插入门窗数据 |
| 收藏 / 管理常用门窗 | 收藏参数，常用门窗库 |

## 编号

- 编号是对象文字属性；插入时可键入，或选"自动编号"按洞口尺寸生成。
- 同一 DWG 内同编号的门窗，洞口尺寸与外观必须一致；`MCJC`（门窗检查）负责查这个。
- `BHSZ` 编号设置：按类型设前缀；`BHCK`/`MCBH` 批量改编号；`BHFW` 编号复位；`BHFZ` 编号翻转；`BHHZ` 加后缀。
- 统计：`MCB`（门窗表，本图）、`MCZB`（门窗总表，多图）。

## 特殊门窗

| 命令 | 对象 | 要点 |
|---|---|---|
| `DXC` 带形窗 | 跨多段墙的连续窗，一个编号 | 起始点 → 终止点 → 逐段选经过的墙（不能漏选） |
| `ZJC` 转角窗 | 墙角处的角窗/角凸窗/落地角凸窗 | 选墙内角 → 转角距离1 → 转角距离2；可设挡板厚 |
| `TC` 凸窗 | 矩形凸窗（外飘窗） | 侧面可设玻璃或挡板，碰墙自动剪裁 |
| `ZHMC` 组合门窗 | 把已插入的多个门窗合成一个对象、一个编号 | 选门窗 → 输编号；用于门连窗/子母门的精细版 |
| `YXD` 异形洞 | 立面闭合 Pline 轮廓开任意洞 | 需先把墙面转 UCS |
| `MCTQ` 门窗填墙 | 保留洞口，里面填墙 | — |
| `MCGZ` 门窗归整 | 按常用规则修门窗与墙的关系 | — |
| `NWFZ` / `ZYFZ` | 批量内外/左右翻转 | 注意 `ZYFZ` 被"自由复制"占用 |
| `MCCS` | 修改立面门窗参数 | 立面图用 |

## 关键限制（自动化必读）

**门/窗"类型"在创建时定死，事后不能用 COM 改。**

- `IsHigh`、`ProStyle`、`Usage`、`DoorLine` 这些属性赋值**不报错但回读不变**（假成功）。
- 想得到"窗"（双线/三线窗图例）而不是"门"（带开启弧），只有两条路：
  1. 插入前在天正面板里选好类型图标（窗 / 门 / 洞 / 凸窗 / 弧窗…）；
  2. 插完后用面板的"替换"功能批量换成目标类型。
- 默认类型受天正上次使用的门窗影响；本机实测默认是 `M1522` 普通门。
- **不要读 `TDbOpening.BayThick`**：抛 `RPC_E_SERVERFAULT`，多次调用会让 acad.exe 崩。

## 可读写属性

| 属性 | 说明 |
|---|---|
| `Width` / `Height` | 洞口宽高 |
| `WinSill` | 窗台高（门为门槛高） |
| `Label` | 编号文字 |
| `Kind`（只读） | 门/窗类别，不可改 |

移动门窗必须用 `Move(VARIANT(VT_ARRAY|VT_R8, [x, y, 0]), ...)`，传 tuple 会 `E_INVALIDARG`。
