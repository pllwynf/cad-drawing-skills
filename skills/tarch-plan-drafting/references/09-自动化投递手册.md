# 自动化投递手册（MCP easy-autocad）

## 工具

| 工具 | 用途 |
|---|---|
| `execute_command` | 投递一条命令 + 多步输入。`mode="com"`（批量）/ `"kbd"`（逐键） |
| `execute_pick` | 起"选择对象型"命令 → 标定 → 按模型坐标点选 → 回车收尾 |
| `count_entity_types` | 按实体/天正类型计数，**验收用** |
| `capture_window` | 抓 AutoCAD 主窗口，返回图片 |
| `zoom` | `extents/all/window/scale` |
| `get_variable` / `set_variable` | 读写系统变量（`OSMODE`、`CLAYER`、`DQBL`…） |

底层库：`C:\Users\<用户名>\mcp-servers\Easy-MCP-AutoCad\autocad_bridge.py`；
标定文件 `pick_calib.json`（同目录）。**改完 `server.py` 要重启 WorkBuddy 客户端**新工具才生效。

## 三类命令 → 三条通道

| 类型 | 命令 | 通道 | 原因 |
|---|---|---|---|
| 纯取点 | `HZQT/TGWall`、`TSingleAxis`、`TRStair`、`TDimMP/ZDBZ` | `execute_command mode="com"` | `SendCommand` 一次把命令+所有输入按序送进去，不丢键 |
| 面板初始化慢 + 逐点 | `BZZ/TGColumn` 点选插柱 | `mode="kbd"`，`per_input_delay ≥ 1.1` | 面板没初始化完，批量投递的点会被吃掉 |
| 选择对象 | `ZWBZ`、`DXBQ`、`MCBZ`、`SBNW`、`QSZW`、`ERASE`（要选实体时） | `execute_pick` | 这些提示只认鼠标点选，**喂坐标无效** |

### com 通道：怎么拼 inputs

`SendCommand` 把 `\n` 当回车，所以把每一步输入按顺序排好、一次发完：

```
TGWall    inputs=["0,0", "10800,9600"]                    # 起点 + 对角点 → 一圈 4 段墙
TGWall    inputs=["0,3600","10800,3600","7200,3600","7200,9600"]   # 连续画两道内墙
TOpening  inputs=["5400,0","9000,0","3600,3600"]          # 每个点插一樘
TSingleAxis inputs=["0,-3000","0,15000","6000,-3000","6000,15000",""]   # 末尾空回车结束
TDimMP    inputs=["0,0","10800,0","5400,-1500","0,3600","3600,0","7200,0","10800,0",""]
```

要点：
- 坐标一律 `x,y`（世界坐标，UCS=WCS）。
- 多点连续取点的命令，**末尾给一个 `""`** 空回车结束；否则命令吊在那里。
- `TDimMP` 是三点式：起点 → 第二点 → 尺寸线位置 → 其余点 → `""`。
- 结果校验：`count_entity_types` 的 `tianzheng_objects` 必须与预期一致。

### kbd 通道

- 逐键 `SendInput`，`sizeof(INPUT)` 在 x64 必须是 **40 字节**，否则静默丢键。
- 依赖 AutoCAD 持有前台。被抢焦时工具会返回 `foreground_owner`（谁抢的），不会假装成功。
- 面板出现后必须 ESC 收面板，否则后续 COM 全被阻塞。

### pick 通道：标定 + 点选

**标定**（`calibrate`）：
1. `OSMODE` 置 0（关捕捉，否则点会吸到附近图元）。
2. 在绘图区取 3 个屏幕像素点，各发一次 `ID` 命令并点一下，从命令日志里回读
   `X = …, Y = …`。
3. 解 `sx = ΔX/Δpx`、`sy = ΔY/Δpy`（sy 为负，屏幕 Y 向下），存基准点。
4. 用第三点反算校验，残差 `err_px` 应 ≤ 2 px。

**为什么不能硬算**：AutoCAD 报的 `SCREENSIZE` 与窗口客户区像素不等（屏幕菜单、命令行占位不同），
`TranslateCoordinates(acWorld→acDisplay)` 返回的也不是像素而是显示坐标系三维点。
只有 `ID` 回读是可信的。

**点选**（`run_pick`）：
```
1. 前台检查 → 不通过直接返回抢占者，不要盲点
2. 标定（指纹 = VIEWSIZE/SCREENSIZE/VIEWCTR/窗口矩形；视图一动就重标）
3. 起命令（kbd）
4. 等提示出现再点（logs 轮询；天正常先跑 Grids 等子命令）
5. 逐点点选，每点前复查前台
6. 回车收尾，次数由 CMDACTIVE 决定（空命令行回车会重复上条命令，不能盲发）
```

已验证可用的点选场景：`ERASE` 选实体精确删除、`ID` 探点、`ZWBZ` 选起始/终止轴。

**已知不稳的地方**：`ZWBZ` 起命令后会弹【轴网标注】面板；面板抢焦点时，残留的回车/ESC
可能把命令取消（日志特征 `请选择起始轴线<退出>:*取消*`）。稳定做法是：
① 轴网必须由 `HZZW` 建真轴网；② 起命令前不要紧贴着一个 ESC；
③ 点选前先用 `SetFocus`（AttachThreadInput）把键盘焦点交回绘图区；④ 每条命令做完再发下一条，
不要连着两条都靠"残留提示"衔接。

## 安全规程

1. **只在新图纸里做**：`create_new_drawing`，命令带 `expected_doc` 安全闸。
   绝不往用户正开着的工程图里发投递（`expected_doc` 不符会直接拒发）。
2. **建图纸立刻落盘**：`doc.SaveAs(路径)`。用 `SAVEAS` 命令会挂住。
   曾因 acad.exe 意外退出丢掉整张演示图。
3. **用户正在操作时不要动**：`panels()` 里出现【门窗参数】【轴网标注】等面板，
   说明用户正在用天正画图 —— 先报告，别抢焦点、别发 ESC。
4. 一次只改一件事，改完立刻 `count_entity_types` 对账。

## 排错对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `AttributeError: <unknown>.ModelSpace` | 天正非模态面板残留，COM 被阻塞 | 发 ESC 收面板；桥已内置自愈 |
| `AttributeError: <unknown>.SendCommand` + `panels_left` 有 `#32770` | 同上 | 同上 |
| 命令投递成功但没生成对象 | 输入顺序不对 / 少了结尾空回车 | `enable_command_log` + `read_command_log` 看实际应答 |
| 按键全丢，无报错 | `sizeof(INPUT)` ≠ 40，或前台被抢 | 看桥的 40 字节自检；看 `foreground_owner` |
| 点选没反应 | 未标定 / 视图动过 / 提示还没出 | 重标定；等提示；放慢 `per_click` |
| 命令被执行两次 | 收尾回车发多了 | 用 `CMDACTIVE` 判次数，别盲发 |
| `E_INVALIDARG (-2147024809)` on Move | 传了 tuple | 用 `VARIANT(VT_ARRAY\|VT_R8,[x,y,0])` |
| `RPC_E_SERVERFAULT` 读 `BayThick` | 已知崩溃点 | 永远别读这个属性 |
| acad.exe 崩了 | 多次读危险属性 / 面板阻塞下强操作 | 重建实例，从已落盘的 DWG 继续 |

## 脚本骨架

```python
import sys, time
sys.path.insert(0, r"C:\Users\<用户名>\mcp-servers\Easy-MCP-AutoCad")
import autocad_bridge as B

DOC = "plan-01"

def new_drawing(path):
    B.esc(3); time.sleep(0.5)
    def mk(acad, _doc):
        acad.Documents.Add(); time.sleep(1.2)
        d = acad.ActiveDocument
        d.SaveAs(path)
        return d.Name
    return B.with_com(mk)

def cmd(name, inputs, wait=1.2):
    r = B.send_command(name, inputs, wait_after=wait, expected_doc=DOC)
    assert r["ok"], r
    return r

def tally():
    return B.entity_tally()["tianzheng_objects"]

# ---- 工序 ----
new_drawing(r"C:\path\plan-01.dwg")
cmd("TSingleAxis", ["0,-3000","0,15000","6000,-3000","6000,15000",""])   # 轴线
cmd("TGWall", ["0,0","10800,9600"])                                      # 外墙环
cmd("TOpening", ["5400,0","9000,0","3600,3600"])                         # 门窗
B.run_pick("ZWBZ", [[0,-2000],[12000,-2000]],
           prompts=["请选择起始轴线","请选择终止轴线"], end="enter")     # 轴号+两道尺寸
print(tally())   # 必须与图纸说明对数
```

## 第四通道：直接 COM 绘图（图元层操作，绕开命令行）

当命令行投递被取消（中文 LISP、面板抢焦点）时，`win32com` 直接在 ModelSpace 里
建图元是可靠的兜底——房间名/引线/台阶/雨篷投影这类**非天正对象**的图元全走这条通道：

```python
import win32com.client, pythoncom
acad = win32com.client.GetActiveObject('AutoCAD.Application')  # 必须GetActiveObject
doc  = acad.ActiveDocument
ms   = doc.ModelSpace
def pt(x, y):
    return win32com.client.VARIANT(pythoncom.VT_ARRAY | pythoncom.VT_R8, (x, y, 0.0))
t = ms.AddText('办公大厅', pt(13100, 8100), 500)   # 字高500(1:100)
t.StyleName = '_TCH_DIM'      # 天正尺寸文字样式，支持中文
t.Alignment = 10              # MiddleCenter
t.TextAlignmentPoint = pt(13100, 8100)
ln = ms.AddLine(pt(x1, y1), pt(x2, y2)); ln.Layer = 'STAIR'; ln.Linetype = 'DASHED'
doc.Regen(0)
```

- 图层先 `doc.Layers.Add(name)` 保证存在；文字样式 `_TCH_DIM` 中文可用（字高 500）。
- COM 建的普通图元天正"不认"，但标注性/装饰性内容（房间名、台阶面砖线、雨篷虚线、
  引出线、坡道箭头）本来就该是普通图元，无碍。
- **删除天正对象也可用 COM**：`obj.Delete()`，遍历 `ms` 按 `obj.ObjectName`
  （`TDbOpening`…）或 `obj.Handle` 过滤，比点选 ERASE 稳。

## 门窗插入铁律（血泪换来的）

1. **一条 MC 连续多点插多樘 = 归属全毁**。每插一樘开洞都会重建所在墙段，
   把先前插好的门窗的墙归属（组码 330）打断成 FREE（游离）。**必须一次只插一樘**：
   `MC → 选类型/参数 → 点一个插入点 → ESC`，逐樘循环。
2. 插入点会漂（捕捉吸到别处 300~400），每樘插完用 `MOVE (handent h) 0,0 dx,dy`
   精确复位到目标坐标，再用 dump 校验。
3. **删错窗别批量重插**：删除→单点重插→MOVE 复位→COM 设 `Width/Height/WinSill/Label`，
   一樘一验证。
4. 归属校验：`dumpent.lsp` 导出全实体组码 → 正则取每樘门窗 handle、插入点(10)、
   宽(40) 高(41) 编号(302)，再看 330 列表：第二项为 0 即 FREE（游离）。
   FREE 的门窗显示仍是嵌在墙上的（门扇线看不出差别），**不查不知道，一开洞就露馅**。
5. 门窗厚（组码 147 / `BayThick`）读会崩 acad.exe、写被拒绝。**窗要和墙同厚，
   唯一办法是删掉在原坐标用 MC 重新插入**（插入时自动取所在墙厚）。

## 面板与对话框

- 天正非模态参数面板（【门窗参数】【轴网标注】…，类 `#32770`）残留会阻塞 COM。
  桥的 `dismiss_panels` 或发 ESC 可收起；但**用户正在操作时先报备**。
- 模态对话框（门窗库、错误报告）用 `win32gui` 枚举窗口按标题找句柄，
  `WM_CLOSE` 或点按钮关闭；关闭后 COM 立即恢复。
- 长会话 COM 会莫名断（RPC 失败）：把操作拆成独立小脚本，每个脚本
  `GetActiveObject` 重连 + 失败重试（最多 6 次、间隔 2s），不要一个进程连跑几十步。

## 楼层复制法（画二三四层/标准层）

1. `shutil.copy` 一层 DWG → L2/L3/L4，COM `doc.Open` 逐张改。
2. **保留**：轴网、轴号、第一二道尺寸、柱、楼梯、外墙环。
3. **删除重建**：全部 `TDbOpening`、内墙（按位置过滤）、房间文字、第三道门窗尺寸。
4. 内墙重画用 `TGWall`（取点型，COM 通道稳）；门窗逐樘 MC（见铁律）。
5. 楼梯层类型（首层下剖断/中间层双剖断/顶层无剖断）COM 不可改，需删了用 `SPLT` 重插，
   或接受保留原样。
6. 图名/标高用 COM AddText（`_TCH_DIM` 样式）。

## 变量速查

| 变量 | 用途 |
|---|---|
| `OSMODE` | 对象捕捉（标定/点选前置 0） |
| `CMDACTIVE` | 是否有命令在跑（0=空闲） |
| `VIEWCTR` / `VIEWSIZE` / `SCREENSIZE` | 视图状态，点选标定指纹 |
| `CLAYER` | 当前图层 |
| `INSUNITS` / `MEASUREMENT` / `LUNITS` | 单位制 |
| `PICKFIRST` | 先选择后执行（部分命令有效） |
| `LOGFILEMODE` / `LOGFILEPATH` | 命令日志（`log_setup` 开启，天正应答都落这里） |
