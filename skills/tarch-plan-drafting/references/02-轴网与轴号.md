# 轴网与轴号

## 概念（必须先理解）

- **轴线不是天正对象**。天正把 `DOTE` 图层上的 `LINE / ARC / CIRCLE` 直接当作轴线识别。
  所以"画轴线"和"有轴号"是两件事。
- **轴号是对自定义对象**（`TDbAxisLabelSet`），大小随当前比例自动缩放，号圈直径默认 8（规范 8~10）。
- **轴网 = 轴线 + 轴号 + 尺寸标注**三套独立系统。轴号和尺寸由 `ZWBZ` 一次性生成，
  但它们之间**不联动**，改轴线后要自己处理轴号。
- 轴线默认用细实线（方便捕捉），出图前用 `ZGXX` 换成点划线。

## 绘制轴网 HZZW（内部名 TRectAxis）

对话框两个页签：**直线轴网 / 圆弧轴网**。

输入方式（三种，任选）：

1. `键入`栏直接敲数据，空格或英文逗号分隔，回车生效。支持倍数写法：
   `4*6000`、`7500`、`4500`。
2. 电子表格里逐行填 `个数` + `间距`。
3. 点 `拾取` 从已有尺寸标注上抄参数（选"上开/下开/左进/右进"之一）。

四个方位：`上开 / 下开 / 左进 / 右进`（开间 = 水平，进深 = 垂直）。
若只填一组方向，会先问"单向轴线长度"，然后才是插入点。

插入提示：`请选择插入点[旋转90度(A)/切换插入点(T)/左右翻转(S)/上下翻转(D)/改转角(R)]`
→ 基点是轴网**左下角轴线交点**，多层建筑同号轴线交点必须对齐。

`轴网夹角` 默认 90°，改它就得斜交轴网。对话框里还有 `删除轴网`（批量删已有轴线）。

## 单轴绘制 DZHZ

- `直轴线`：起点 → 终点，可连续画，右键结束。
- `弧轴线`：同 ARC 的三点/圆心方式。
- `出头长度`：轴线比点取点超出的长度（弧轴线按弧长）。
- 与 `TSingleAxis`（投递用内部名）行为一致，但 DZHZ 会先弹【单轴绘制】面板设出头长度。

## 轴网标注 ZWBZ（关键）

命令：`ZWBZ` / `TMultAxisDim`。生成**轴号 + 第一二道尺寸**。

交互：

```
请选择起始轴线<退出>:        点第一根轴（在一侧点，决定标注在哪一侧）
请选择终止轴线<退出>:        点最后一根轴
请选择不需要标注的轴线:      选辅助轴（可空回车跳过）
请选择起始轴线<退出>:        回车退出
```

面板选项：`起始轴号`（水平默认 1、垂直默认 A）、`轴号排列规则`（变前项/变后项）、
`共用轴号`（接上一组编号继续）、`对侧标注`、`单侧/双侧标注`、`删除轴网标注`。

**为什么我的自动投递会失败**：`ZWBZ` 内部先跑一遍 `Grids`（找轴网），找不到真轴网就直接
`*取消*`。日志特征：

```
命令: ZWBZ → TMULTAXISDIM → 命令: Grids → 命令: TMultAxisDim → 请选择起始轴线<退出>:*取消*
```

对策：轴网必须由 `HZZW`（TRectAxis）生成，别拿 `TSingleAxis` 画的直线冒充轴网去标注。

## 单轴标注 DZBZ

只标一根轴，编号独立，不与轴号系统关联。常用于详图、立剖面。
面板支持单轴号 / 多轴号文字 / 多轴号图形 / 连续轴号（起止轴号）四种模式；
命令行 `点取待标注的轴线或[手工绘制(D)]<退出>`。

## 轴号规则（GB/T 50001）

- 水平方向用数字（1、2、3…），垂直方向用大写字母（A、B、C…）。
- **I、O、Z 不用于轴号**，排序时自动跳过。
- 1 号轴与 A 号轴之前不加主轴号；附加轴号分母为 `01`、`0A`。
- 分区轴号两种规则：
  - 变前项：`AA, BA, CA …`；`A1, B1 …`；`A-A, B-A …`
  - 变后项（默认）：`AA, AB, AC …`；`A1, A2 …`；`A-A, A-B …`

|---|---|---|
| `TJZX` 添加轴线 | 参考已有轴加一根并插入轴号 | 选参考轴 → 键入距离；可选"重排轴号""附加轴号" |
| `SCZX` 删除轴线 | 删轴 + 轴号，可选合并尺寸/重排轴号 | 面板两个勾选框组合出四种结果 |
| `SCZH` 删除轴号 | 只删轴号，其余自动重排 | — |
| `TBZH` 添补轴号 | 关联增加新轴号 | — |
| `CPZH` 重排轴号 | 一组轴号重排 | — |
| `DPZH` 倒排轴号 | 立剖面用 | — |
| `ZXCJ` 轴线裁剪 | 矩形/多边形/取齐三种 | 先 `F` 取齐、`P` 多边形 |
| `ZWHB` 轴网合并 | 多组轴网延到对齐边界并去重 | 只支持正交轴网 |
| `YZDH` 一轴多号 | 一根轴多个轴号 | — |
| `ZFZH` 主附转换 | 主轴号 ↔ 附加轴号 | — |
| `ZHYX` 轴号隐现 | 隐藏/恢复轴号 | — |
| `ZGXX` 轴改线型 | 连续线 ↔ 点划线 | 模型空间线型比例 = 10×当前比例 |
| `QSZW` 墙生轴网 | 按墙基线反推轴线（无轴号无尺寸） | 选墙 → 回车 |

## 圆弧轴网

`HZZW` → 圆弧轴网页签：`圆心角` + `进深`。标注时：
选起始径向轴 → 终止径向轴 → 是否逆时针（默认 Y）→ 完成。
环向进深轴号要用第二次 `ZWBZ` 单独标（会额外问"请选择圆形轴网的横(径)线"）。
