# 标高标注 BGBZ 与「对话框型命令」自动化（实测）

> 来源：`D:\工作安装软件\cad\SYS\TArch.chm`（T20 天正建筑 V9.0 帮助，2022-10-27）
> 章节：`03T20/T20符号/坐标标高符号.htm` → 「标高标注」
> 实测：2026-10-23 于 AutoCAD 2022 + T20 V9.0，测试图 `Drawing15.dwg`

## 一、命令与手册原文要点

| 项 | 内容 |
|---|---|
| 菜单 | 符号标注 → 标高标注 |
| 命令 | `BGBZ` |
| 内部宏 | `TMELEV`（日志里紧跟在 BGBZ 后面） |
| 对象类 | `TDbSymbElevation`（天正标高对象，非块、非文字） |

手册明确规定：

1. 对话框分两页：**建筑标高**（平面楼层标高、立剖面楼面标高）与 **总图标高**（地坪、绝对/相对标高换算）。
2. **不勾「手工输入」时，自动取光标所在的 Y 坐标作为标高数值**；勾选后在表格里填楼层标高。
3. 建筑标高精度自动切 `0.000`；总图标高自动切 `0.00`。
4. 「多层标高」按钮可一次算出多行：填起始标高 + 起始层号 + 层数 + 层高 → 添加。
5. 「楼层标高自动加括号」按《房屋建筑制图统一标准》10.8.6 处理多层标高。
6. 「自动对齐」（仅建筑标高）让后续标高保持同方向并竖向对齐。
7. 双击文字 = 在位编辑改数值；双击非文字部分 = 对象编辑对话框。
8. 「动态标注」对**手工输入的标高不起作用**（防止误改）。

## 二、实测交互序列（可靠）

```
BGBZ → [弹出模态对话框「标高标注」] → 回车(默认「确定」)
     → 请点取标高点或 [参考标高(R)]<退出>:  ← 此时鼠标点取
     → 每点一次生成一个标高对象，命令持续等待下一点
     → ESC / 回车 结束
```

生成结果验证（测试图，两条参考线 y=0 / y=3600）：

```
TDbSymbElevation  h=E5  bbox(1200,3600)-(2508,4302)  Text = '3.60000'
TDbSymbElevation  h=E4  bbox(-9,128)   -(1251,830)    Text = '0.12755'
```

**取点 Y=3600（毫米）→ 标高文字 `3.60000`（米，5 位小数显示但精度设 3 位）。**
所以：把立面画在 Y=0 基准上，BGBZ 点取即可得到正确标高，无需手工填数。

## 三、三个必须知道的坑

### 1. 键入坐标无效，只能鼠标点

`请点取标高点` 阶段用 `type_line("500,3600")` 会被当成 AutoCAD 命令：

```
未知命令“500,3600”。按 F1 查看帮助。
```

天正这一步走 Grread 直接取点，不接受命令行坐标。**必须走 `world_to_screen` + 真实鼠标点击。**

### 2. 对话框必须用「回车」确认，不能用 WM_COMMAND / BM_CLICK

| 方式 | 结果 |
|---|---|
| `press_vk(VK_RETURN)` | ✅ 对话框关闭，正常进入 `请点取标高点` |
| `SendMessage(btn, BM_CLICK)` | ❌ 对话框关闭，但命令随即 `*取消*` |
| `PostMessage(top, WM_COMMAND, IDOK, btn)` | ❌ 同上，`*取消*` |

推测：异步消息让 Modal 循环重入，天正命令状态机判定异常后自取消。

### 3. 视图必须先 ZoomExtents，否则标定"自洽但无用"

`calibrate()` 用 3 个屏幕定点回读世界坐标解 `sx/sy`，**残差为 0 也可能完全错位**——
因为它只保证三个探针自洽，不保证目标点在视口内。

实测：视图未缩放时世界范围只有 x∈[149,432], y∈[68,182]，
`world_to_screen(500,3600)` 算出 `py = -9585`（屏幕外），点击静默失效。

**调用前必须：`a.ZoomExtents()` → `calibrate()` → 逐点校验落点在视口 rect 内。**

## 四、对话框控件 ID 表（`标高标注`，#32770）

用 `EnumChildWindows` 取到的稳定 ID，可直接 `GetDlgItem` 定位：

| ID | 类 | 含义 |
|---|---|---|
| 1 | Button | 确定 |
| 2 | Button | 取消 |
| 1110 | SysTabControl32 | 建筑标高 / 总图 页签 |
| 1086 | Button | 手工输入（复选框） |
| 1109 | Button | 文字齐线端 |
| 1130 | Button | 文字居中 |
| 1106 | Button | 楼层标高自动加括号（未勾选时 disabled） |
| 1108 | Button | 标高说明自动加括号 |
| 1138 | Button | 多层标高（未勾选手工输入时 disabled） |
| 1051 | ComboBox | 文字样式 |
| 1052 | ComboBox | 字高 |
| 1084 | ComboBox | 精度 |
| 1053 | ComboBox | 文字位置 |
| 1001 | Edit | 字高数值 |
| 1125 / 1127 / 1118 | Edit | 绝对标高 / 相对标高 / 换算关系（总图页） |
| 1079/1080/1081/1082/1083/1085/1087/1398 | Button(26×26) | 图标按钮：实心三角 / 基线 / 引线 / 清空 / 自动对齐 等 |

`BGDQ` 标高对齐、`BGGZ` 标高改值、`BGJC` 标高检查 是同族配套命令。

## 五、可复用驱动代码

`scripts_work/wangfan/tz_dlg.py` 的 `drive_dialog_command(cmd, points, expect_prompt)`：

1. `dismiss_panels` 清残留 → `soft_foreground`
2. `ZoomExtents`（调用方负责）→ `calibrate()`
3. `type_line(cmd)` 起命令 → 等 `panels()`
4. `press_vk(0x0D)` 确认默认参数
5. `wait_prompt(expect_prompt)`
6. 逐点 `world_to_screen` → `click_screen`
7. `esc(2)` 收尾

**同一个骨架适用于所有「先弹对话框、再点取」的天正命令**（`TMBZ` 图名标注、
`PQFH` 剖切符号、`HZBZ` 画指北针、`JTYZ` 箭头引注 等）。
